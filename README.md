# 2026_01_18_unity_nes_multi_controller

<img width="1845" height="1075" alt="image" src="https://github.com/user-attachments/assets/6007083c-d986-40ce-a6e3-c206dcc6f6a5" />

Mini-game design to speak about text and bytes in UDP that you can send and receive.
Send is easy but receive require threads.

NES UDP Controller to play at the game:   
https://github.com/EloiStree/2026_01_18_upm_nes_controller_udp.git   

You can send input instruction to port 3615/3614
Your received state of the game on port 4615/4614

This type of game is what I call a TBIO (Text Byte In Out)
